# rime-config

这是我自己使用的 rime 配置：

## 输入法

- 默认输入法：**小鹤双拼 + 雾凇拼音**

## 中英文切换

- **Caps Lock** 切换中英文
  - 中文模式下按 Caps → 提交当前输入的英文字母 + 切换到英文模式
  - 英文模式下按 Caps → 切换回中文模式
  - 禁用 Shift 切换中英文
- 关闭中英文切换时的显式提示（A / 中）

## 快捷键

- `F4` 调用其他输入法/方案切换
- 上下键（↑↓）翻页候选词
- 左右键（←→）选择候选词
- `-` / `=` 翻页（保留）
- `[` / `]` 以词定字（选词首字/尾字）
- `Alt + ←/→` 移动拼音光标
- `Tab` / `Shift + Tab` 移动拼音光标

## 词库

- 基于雾凇拼音词库，支持自动学习用户输入词频
- 输入过的词汇会自动记录到用户词典
